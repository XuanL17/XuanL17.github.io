Making Human Studies as Reproducible as Open-Source Code

Xuan LiuMarch 10, 2026—views
English中文

In machine learning, we’re used to picking up where someone else left off. Find a model on Hugging Face, download a dataset, run the public code, then change something and try our own idea. I think this ability to build directly on someone else’s work is one of the field’s biggest strengths.

When I read a social science paper, though, I often get stuck at “I’ve read it.” The experiment is interesting. I want to try something: what if we changed the wording? Or one of the conditions? Would the result still hold?

To actually do that, I first have to reconstruct the materials, conditions, and procedure, then work out how the original analysis was done. Running it again with human participants also involves ethics review and recruitment. A small change can end up requiring a whole study to be built from scratch.

I wish a published study could leave behind an experiment that someone else could simply open and run. What participants saw, what they did, how the conditions differed—all of that would be there.

With LLMs, we can start by having agents play the participants: read the same questions and make the same choices. Then change a condition and see what happens. The simulated results still need to be checked in human studies, but at least an idea can get started.

These experiments can also help us design agents. Keep the materials and procedure the same, change the model, prompts, or participant settings, and compare the results with the human findings. We can then see where an agent behaves like people, where it doesn’t, and what to change next.

My advisor recommended David Donoho’s Data Science at the Singularity, which discusses frictionless reproducibility. My takeaway was that research can move quickly when people can use each other’s data, run each other’s code, and compare results using the same standards. One person’s work can quickly become the starting point for someone else’s idea. I want that to be possible for human studies too.

That’s what led me to start building HumanStudy-Hub: working with a community to turn published human studies into experiments that others can reuse and run. The tasks and human results can also serve as benchmarks for agents, to see whether they show similar behavior. The experiments can become a gym where we repeatedly test and adjust agents playing the participants. HumanStudy-Bench is a step in that direction.
