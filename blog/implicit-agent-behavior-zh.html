Can Implicit Language Reliably Control Agent Behavior?

Xuan Liu2025年9月16日—次浏览
English中文

做 social simulation 时，我们常常先给 agent 写一段人物描述：职业、性格、家庭、经历。描述可以很细，细到它和谁是朋友、平时喜欢做什么。

这种做法依赖两个前提：

  • LLM 能识别隐含语言中的细微线索。
  • 识别之后，LLM 能按设定扮演角色。

比如，让 LLM role-play 一个经济学家，我们期待的不只是它用经济学家的口吻说话，也包括它做决定时更不容易受到措辞影响。但 prompt 里只写了“经济学家”，具体该表现出什么行为，仍由模型自己理解。

我们用框架效应做了一个测试。给 agent 普通人、经济学家和空白三种设定，让四个模型回答同一组题目，看看这些期待有没有发生。

结果是，同一份设定在不同模型上产生了不同的行为；人物之间的差异，也没有可靠地符合预期。Mistral 上，三种设定的行为很接近；DeepSeek 上，经济学家反而比普通人更容易受框架影响。

这意味着，我们写下的角色，并没有直接变成我们想要的行为。模型也参与了这个定义过程。

怎样让 agent 的行为可量化、可复现？我们开发了 CoBRA，一个用于定量指定和校准 agent 行为的工具包。
